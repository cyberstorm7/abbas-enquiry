Abbas Enquiry - Android (WebView + AdMob banner)

Android Studio ke bina (GitHub se APK):
1. github.com par free account banao -> New repository (naam: abbas-enquiry)
2. Is folder ki saari files repo me upload karo (.github folder samet)
3. Actions tab -> "Build APK" -> Run workflow
4. 3-5 min baad run khulo -> neeche Artifacts me AbbasEnquiry-APK download karo
5. APK phone me install karo

keystore-SAMBHAL-KE-RAKHO artifact bhi download karke rakho (release.jks).
Agle update ke liye use repo ke app/ folder me daal dena, taaki purani app ke upar update ho sake.

Release APK me aapka real ad unit hota hai. Apne ads khud tap mat karna.
